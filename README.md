# Job Vacancy NLP

### 🌍 Overview

Using NLP, candidates for a job vacancy are automatically ranked with the opportunity to re-rank via human intervention if necessary.

Candidates for a job vacancy are ranked based on how similar their current job title is to the vacant job title. 

Initially, the candidates are ranked based on the cosine similarity between the vectors generated by a basic SBERT model.

Then, there is the opporunity to manually 'star' candidates that should be ranked higher than they are.

These updated rankings are then used to train a neural network built on RankNet architecture, giving a model that can rank a new candidate based only on their job title.

### 🧼 Data Cleaning

[EDA Notebook](/notebooks/exploratory_data_analysis.ipynb)

The data contained information about 104 candidates for the job.

- Unique ID
- Current job title
- Location
- Number of online connections

The location and number of online connections provided no use in this project, with the current job titles being the relevant information and the unique IDs used to distinguish the candidates.

During cleaning, there were found to be many duplicates. Once removed, there were 53 unique candidates remaining.

The job titles were formatted using RegEx. Then a column containing stemmed versions of the job titles was created using PorterStemmer.

### 📈 Vectorisation

Several different methods of vectorisation were used to generate embeddings for the job titles

- [TF-IDF](/notebooks/tf_idf.ipynb)
- [FastText](/notebooks/FastText.ipynb)
- [BERT](/notebooks/BERT.ipynb)
- [SBERT](/notebooks/SBERT.ipynb)

For each, the cosine similarity was used to determine the similarity between the vacant job title and each candidates current job title. This was then converted into a ranking.

Upon manual assessment, SBERT was deemed to generate the most accurate ranking and was carried forward for use in the neural network.

### 📈 RankNet

[RankNet Notebook](/notebooks/RankNet.ipynb)

The opportunity to 'star' candidates was created. A starred candidate would move from their originial rank according to the SBERT embeddings up to the top of the rankings. This allowed a manual input into the rankings. If no edits needed to be made, the rankings based on the SBERT embeddings would remain.

Using PyTorch, a neural network was created containing the input layer, 2 hidden layers, 2 dropout layers and the output layer. Feeding in 2 candidates, with their job titles and related embeddings, returns an output of which of the 2 should rank higher. 

Training this neural network on several thousand random pairs of candidates allows it to learn how ideal a candidate is based on the embeddings of their current job title. 

Passing an individual in to the neural network returns a score - the higher the score, the better match the candidate is for the vacant job role. The scores of all candidates were turned into a rankings.

Using this, the employer is able to automate the process of ranking candidates while also being able to manual edit the rankings if they see fit.
